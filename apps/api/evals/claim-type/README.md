评测对象：线上 `claimJudge` 用的同一份提示词（`prompt.txt`）。
判定分两层，都在本地跑，**不进 CI / `check-dev.sh`**：

1. **结构层**：输出能解析成三类之一（陈述 / 演示 / 寒暄）；
2. **闸门层**：只比「可引用 / 不可引用」——**陈述 = 可引用，演示 / 寒暄 = 不可引用**。

> 为什么只测二值：闸① 实际只派生 `is_citable`。四类时「事实 / 观点」在闸门上结果相同，

## 片级主类规则（ADR-034 A1 + ADR-035 三类）

一片只能有一个主类，按**整片占主体篇幅的内容**判，不要因为片里出现一个词就改判：

1. 整片都是寒暄、没有训练或营养内容 → **寒暄**；
2. 整片主体是跟练口令 / 示范流程（带着观众做动作），技术讲解为辅 → **演示**；
3. 整片主体是说明、主张、建议、要领、定义、数字 → **陈述**；
4. 两类篇幅相当、无法区分时，按 **演示 > 陈述** 取靠前者。

规则同时写进了 `prompt.txt` 与标注口径（`label_basis = rule_A1_dominant`）。
